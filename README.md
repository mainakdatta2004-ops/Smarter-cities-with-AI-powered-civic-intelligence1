# Civic Intelligence — Spatial Systems for Smarter Cities

> **Ethereal 3D Storytelling · Deep Glassmorphism UI · Bento Grid Layout · Soft Pastel Gradient Palette · Responsive Web Design**

An ambient spatial computing layer for urban governance. Civic Intelligence integrates mobility, public safety, utilities, and democratic citizen engagement into a single responsive, continuous feedback loop.

---

## 🌟 Key Architectural & Visual Features

### 🎨 Ethereal 3D Storytelling & Ambiance
- **Floating Gradient Orbs**: Animated background orbs (`orb-1` through `orb-5`) that slowly drift across the viewport creating ambient lighting depth.
- **Aurora Band**: An animated color-sweep layer across the upper backdrop.
- **3D Tilt & Mouse Glow**: Interactive bento cards feature subtle 3D tilt transformation (`rotateX`, `rotateY`, `translateZ`) with radial glow coordinates tracking mouse movement.
- **Scroll-Reveal System**: Smooth `IntersectionObserver`-powered fade & rise reveal animations for staggered bento elements as the user scrolls.

### 🔮 Premium Glassmorphism UI
- **Deep Frosting**: Multi-layered backdrop blurs (`40px` to `60px`) for translucent cards.
- **Iridescent Borders**: Gradient glow borders surrounding glass elements on hover and selection.
- **Noise Overlay**: Subtle SVG noise texture for physical depth and realism.
- **Spatial Floating Navbar**: Glassmorphic pill navigation sticky at the top of the viewport with a pulsing status dot.

### 🍱 Asymmetric Bento Grid Layout
- **Hero Bento Grid**: Structured headline and live system metrics telemetry panel.
- **Civic Layers Bento**: Interactive 2×2 asymmetric grid with a featured layer spanning the top row.
- **Bento Stats Strip**: Gradient numerical metrics highlighting urban delay reduction, dispatch speed, and citizen engagement gains.
- **Shadows in the Smart City (Risk Bento)**: 2-column bento analysis detailing data privacy, algorithmic bias, digital divide, and automation over-reliance risks.

### 🌸 Soft Pastel Gradient Palette
- **Twilight Slate Base**: Deep slate background (`#0b0e18`) replacing high-contrast black for visual stress reduction.
- **Curated Pastel Accents**: Soft lavender (`#a78bfa`), rose-pink (`#f0abcf`), mint (`#6ee7b7`), warm peach (`#fbbf8e`), and sky blue (`#7dd3fc`).

## 🚦 Interactive Systems & Simulation Widgets

1. **Layer 01 // Mobility (Traffic Flow Controller)**
   - Live signal light cycle simulation (Adaptive AI mode vs. Fixed Schedule).
   - Dynamic traffic delay calculations with clickable "Trigger Congestion Spike" event simulator.
2. **Layer 02 // Protection (Public Safety & Emergency Dispatch)**
   - Real-time emergency dispatch log terminal with dynamic event ticker.
   - Ethical Hotspot Allocation toggle to prevent spatial policing bias.
3. **Layer 03 // Infrastructure (Smart Utilities & Grids)**
   - Interactive Solar and Wind renewable energy feed sliders with live percentage indicators.
   - SVG Acoustic Leak Detector with real-time wave animation and pipe scan trigger.
4. **Layer 04 // Democratic Feedback (Civic Voice & Citizen Engagement)**
   - Interactive NLP Sentiment Analysis Board for resident proposals.
   - Live proposal submission input that categorizes comment sentiment into Positive, Neutral, or Negative in real time.
5. **Field Deployments**: Real-world case study tabs for Singapore (Virtual Singapore), Barcelona (Sentilo & Superblocks), and Seoul (S-Dot & Digital Mayor).
6. **Ethical Framework & Synthesis**: Interactive spatial governance layer stack and governance reflection toggle.

## 🛠️ Technology Stack

- **Core**: React 18, Vite 5, JavaScript (ES6+)
- **Styling**: Vanilla CSS3 with CSS Custom Properties, Flexbox, CSS Grid
- **Fonts**: Manrope, Inter, JetBrains Mono (via Google Fonts)
- **Deployment & Server**: Node.js, Express

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/mainakdatta2004-ops/Smarter-cities-with-AI-powered-civic-intelligence1.git

# Navigate into project directory
cd Smarter-cities-with-AI-powered-civic-intelligence1

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
